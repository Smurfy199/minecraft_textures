# minecraft_textures

Images hosted for the **Signed Paintings** mod on our Minecraft server.

## Using an image in-game

Write the image's raw link on a sign:

```
https://raw.githubusercontent.com/<github-user>/minecraft_textures/main/<file-name>
```

For example, `nova_bar.jpg` is at:

```
https://raw.githubusercontent.com/<github-user>/minecraft_textures/main/nova_bar.jpg
```

## Adding a new image

1. Drop the `.png` or `.jpg` into this folder. Use short names with no spaces, since sign space is limited.
2. Commit and push:
   ```
   git add .
   git commit -m "Add <image name>"
   git push
   ```
3. The link works for everyone within a minute or so.
